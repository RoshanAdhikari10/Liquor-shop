# 🍷 KungTung — Liquor Shop Website

KungTung is a modern liquor shop e-commerce website built with **PHP, MySQL, Bootstrap, and JavaScript**. It provides customers with an easy way to browse products, manage their cart, and place orders, along with an admin panel for managing the store.

## ✨ Features

* 👤 User Registration & Login
* 🥃 Browse Liquor Products
* 📂 Product Categories & Filtering
* 🛒 Shopping Cart
* 📦 Order Management
* 📊 Admin Dashboard
* 🏷️ Product & Category Management
* 📦 Stock Management
* 📱 Responsive Design

## 🚀 Installation

1. Install **XAMPP**.
2. Clone or download this repository.
3. Move the project folder into:
   `xampp/htdocs/`
4. Start **Apache** and **MySQL** from XAMPP.
5. Create a MySQL database named `kungtung`.
6. Import the project's SQL database file into phpMyAdmin.
7. Open the website in your browser:

```text
http://localhost/kungtung/
```

### Admin Panel

```text
http://localhost/kungtung/admin/
```
